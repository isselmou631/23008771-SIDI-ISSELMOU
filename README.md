
# Projet F1 – Prédiction du risque de crédit en Allemagne

## 1. Présentation du projet

Ce projet porte sur la prédiction du risque de crédit en Allemagne à l'aide des techniques de Machine Learning.

L'objectif est de développer un modèle capable de distinguer les bons et les mauvais profils de crédit afin d'aider les établissements financiers dans leurs décisions d'octroi de crédit.

## 2. Problématique

Comment prédire le risque de défaut de crédit d'un demandeur à partir de ses caractéristiques financières et personnelles ?

## 3. Algorithme utilisé

L'algorithme principal utilisé dans ce projet est Random Forest (Forêt aléatoire), un algorithme de classification supervisée.

## 4. Dataset

Jeu de données : German Credit.

Il contient des informations relatives aux demandeurs de crédit en Allemagne.

- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
